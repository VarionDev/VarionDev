## 🧪 Philosophy | فلسفه توسعه

- Systems over shortcuts | سیستم‌ها مهم‌تر از میان‌برها  
- Working code over perfect code | کد عملی مهم‌تر از کد بی‌نقص  
- Learning by doing | یادگیری از طریق انجام دادن  
- Depth over speed | عمق مهم‌تر از سرعت  
- Consistency over motivation | تداوم مهم‌تر از انگیزه  

> Progress is engineered, not wished for | پیشرفت ساخته می‌شود، آرزو نمی‌شود.
